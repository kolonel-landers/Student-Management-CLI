# 🎓 Student Management CLI

A Python Command Line Interface (CLI) application to manage students and their grades.

---

## 📌 Overview

This project allows me to:

* Manage students
* Store their grades
* Calculate averages
* Search and display data

It is built with a **clean and scalable architecture**, following good development practices.

---

## 🎯 Objectives

This project was created to:

* Practice Python fundamentals
* Learn clean code structure
* Understand separation of concerns
* Build a maintainable and scalable application

---

## ⚙️ Features

* Add a new student
* Add grades to a student
* View all students
* Calculate a student's average
* Search for a student by name

---

## 🏗️ Project Structure

```
gestion_notes/
├── venv/          # Virtual environment
├── main.py        # Entry point (CLI logic)
├── models.py      # Data structure
├── services.py    # Business logic
├── utils.py       # Helper functions
```

### 🔍 Explanation

* **models.py** → defines data structure
* **services.py** → contains core logic
* **utils.py** → helper/display functions
* **main.py** → user interaction (CLI)

---

## 🧪 Installation & Setup

```bash
python -m venv venv
venv\Scripts\activate   # Windows
python main.py
```

---

## 🚀 Usage

1. Run the application
2. Choose an option from the menu
3. Enter the student name
4. Enter grades separated by commas (e.g: 12,15,18)

---

## 🧠 Concepts Learned

* Loops (`for`, `while`)

* Modular architecture
* Data handling

---

## 🧠 Mindset & Approach

This project follows best practices:

* Separation of concerns

* Reusable functions

---

## 🚀 Future Improvements

# 🎓 Gestion des étudiants (CLI Python)

Application Python en ligne de commande (CLI) permettant de gérer des étudiants et leurs notes.

---

## 📌 Présentation

Ce projet permet de :

* Gérer des étudiants
* Enregistrer leurs notes
* Calculer leurs moyennes
* Rechercher et afficher des informations

Il est conçu avec une **architecture propre et évolutive**, en respectant les bonnes pratiques de développement.

---

## 🎯 Objectifs

Ce projet a été réalisé pour :

* Pratiquer les bases de Python
* Apprendre à structurer un projet proprement
* Comprendre la séparation des responsabilités
* Construire une application maintenable et scalable

---

## ⚙️ Fonctionnalités

* Ajouter un étudiant
* Ajouter des notes à un étudiant
* Afficher tous les étudiants
* Calculer la moyenne d’un étudiant
* Rechercher un étudiant par son nom

---

## 🏗️ Structure du projet

```bash
gestion_notes/
├── venv/          # Environnement virtuel
├── main.py        # Point d’entrée (logique CLI)
├── models.py      # Structure des données
├── services.py    # Logique métier
├── utils.py       # Fonctions utilitaires
```

### 🔍 Explication

* **models.py** → définit la structure des données
* **services.py** → contient la logique principale
* **utils.py** → fonctions d’affichage et aides
* **main.py** → interaction avec l’utilisateur

---

## 🧪 Installation & Configuration

```bash
python -m venv venv
venv\Scripts\activate   # Windows
python main.py
```

---

## 🚀 Utilisation

1. Lancer l’application
2. Choisir une option dans le menu

4. Entrer les notes séparées par des virgules (ex : 12,15,18)
